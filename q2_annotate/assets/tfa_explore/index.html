Individual samples

The 100 samples with the highest loads are shown; the group comparison uses every sample. Colors match the groups labeled in the panel on the left.

Loads are abundance-weighted function counts. The heatmap metric summarizes each pair across all samples, including zero loads. Taxa sharing a lineage at the selected level are summed within each sample before calculating the heatmap metric. Heatmap labels use the last classified rank when deeper ranks are missing. Matching pairs are summed within each sample for the boxplots and sample bars. Metadata groups apply to those sample plots. Missing metadata is shown as its own group.
